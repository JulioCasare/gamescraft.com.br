# Site da Game Craft

Esta ramificacao existe so para **hospedar o site** no GitHub Pages. O arquivo
que vale e o `index.html`, e ele e autossuficiente: a arte vai embutida dentro
dele, entao nao ha imagem solta para se perder.

O `.nojekyll` desliga o processador de blog do Pages, que nao serve para nada
aqui e so atrapalha arquivo que comece com sublinhado.

Para trocar o site: substitua o `index.html` e faca commit. O Pages publica
sozinho em um ou dois minutos.
